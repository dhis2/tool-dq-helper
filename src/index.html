Instructions

This app helps you set up automated data quality checks for your DHIS2 data elements. It creates three types of quality metrics:

  • Outliers: Identifies values that deviate significantly from the average
  • Consistency: Checks if reported values are consistent across periods
  • Completeness: Monitors if data is being reported as expected

How to use

  1. Select a data set to filter available data elements
  2. Choose the data element you want to configure quality checks for
  3. For disaggregated data elements, choose how to handle completeness:
    • Use one category option as a proxy for all
    • Count as complete when any category has data
  4. Select the organisation unit level where data is collected
  5. Set the threshold for outlier detection (standard deviations from mean)
  6. Click Preview to review the configuration before importing
